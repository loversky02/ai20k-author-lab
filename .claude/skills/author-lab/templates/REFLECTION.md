# REFLECTION — _(điền)_ (Họ tên – MSSV)

Tối đa <FILL: 300> từ. Dẫn số và id từ lần chạy của chính bạn; câu chung chung không được điểm.

1. **Kết quả chính** — con số nào bạn đo được, nó nói gì, nó **không** chứng minh điều gì?
2. **Một quyết định** — bạn chọn gì, phương án bị loại là gì, vì sao?
3. **Một chỗ sai** — chỗ nào code / judge / AI của bạn sai, bạn phát hiện bằng cách nào?
4. **Dùng AI** — công cụ, dùng cho việc gì, bạn đã sửa hoặc bỏ gì sau khi kiểm tra. Không dùng thì ghi "Không dùng".
